# Single-player endless run with an upgrade draft

The game is a single-player, endless arena run. Each stage pits the player against AI rivals; clearing it opens an intermission where the player picks one of three upgrades that lasts for the rest of the run. Difficulty scales with the stage number, and the run ends when lives run out, so the long-term loop is score chasing and build shaping rather than a fixed campaign. Local and online multiplayer are deliberately out of scope for v1; AI rivals carry the strategic pressure and keep the game playable solo.

**Considered Options**: a fixed 10-stage campaign, local two-player versus, or online multiplayer. The endless run gives the longest play per unit of content, the upgrade draft adds run-defining decisions, and single-player avoids the input, networking, and matchmaking work that would crowd out the core game.
